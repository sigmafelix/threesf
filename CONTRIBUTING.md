# Contributing

- Core geometry code lives in `include/threesf/` and is header-only; keep it free of
  third-party dependencies.
- Every algorithmic change needs a test against an analytic ground truth in
  `tests/test_threesf.cpp`; every I/O change needs a round-trip case in
  `tests/test_io.cpp` (ideally with a fixture generated by PostGIS, sf or shapely).
- Run the full matrix locally before opening a PR:

  ```sh
  cmake -S . -B build && cmake --build build && ctest --test-dir build --output-on-failure
  pip install -e ./python && pytest python/tests
  R CMD build r/threesf && R CMD check threesf_*.tar.gz --as-cran
  ```

- The C ABI (`include/threesf/threesf_c.h`) is the contract for both wrappers. Add new
  entry points there first, then expose them in `python/threesf/__init__.py` and
  `r/threesf/R/threesf.R` + `r/threesf/src/threesf_r.cpp`.
- Formatting: 4-space indent, 120 columns, `clang-format` config in repo root.
